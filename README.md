# 大学英语六级核心词汇备考工作台

一个单文件的 CET-6 刷词网页，收录 699 个词条，覆盖核心动词、形容词和副词、名词、写作与翻译表达、逻辑衔接与介词短语。可以按自己的节奏学习，随时回测已掌握词汇，把忘记的词放回未掌握词库。

## 开始使用

下载此仓库后，用浏览器打开本地的 [六级.html](./六级.html)。页面默认平铺全部词汇，也可切换为每页 24、48 或 96 词。项目使用原生 HTML、CSS 和 JavaScript，打开即可使用。

## 自由刷词

- **打卡与掌握**：点击「打卡 +1」累计复习次数，点击「−1」撤回一次打卡。卡片上的「未掌握／已掌握」按钮独立切换，打卡次数与掌握状态分别记录。从已掌握切回未掌握会增加一次遗忘记录，可通过「撤销掌握修改」恢复最近一次操作。
- **组合筛选**：按掌握状态、打卡次数、分类、真题考点、遗忘记录或关键词缩小范围。支持随机打乱、按遗忘次数排序，以及按最近一次打卡时间优先复习最久未打卡的词。
- **翻牌自测**：点击「隐藏释义」遮挡答案，再逐词翻牌核对释义与搭配。点击「显示释义」恢复全局显示。卡片上的扬声器按钮调用浏览器朗读。
- **随机抽查**：从当前筛选结果中抽取 20、50、100、200 词、自定义数量或全部匹配词汇。抽中的词平铺显示，顺序保持到重新抽取或退出。退出后恢复完整筛选结果。

## 随机抽词冲刺

冲刺以单词卡片逐个展示，支持按全部、掌握状态、未打卡、曾经遗忘或当前分类抽词。冲刺中修改的打卡次数和掌握状态会同步反映在词库列表和统计看板。

| 桌面快捷键 | 操作 |
| --- | --- |
| `Space` | 翻牌显示释义 |
| `Enter` | 打卡并进入下一词 |
| `←` / `→` | 上一词 / 下一词 |

## 学习记录与备份

学习记录和显示偏好保存在当前浏览器的 `localStorage`。切换设备、浏览器或访问地址前，可以在看板中选择「备份 JSON」，再在新的环境中选择「导入 JSON」恢复数据。确认导入后，备份会替换当前学习记录和显示偏好。

看板也可导出全部词汇或未掌握词汇的 CSV，方便在表格中查看打卡次数、掌握状态和遗忘次数。恢复进度请使用 JSON 备份。重置学习记录需要连续确认两次。
